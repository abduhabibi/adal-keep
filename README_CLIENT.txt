🚀 ADAL KEEP - Quick Start Guide

ONE-TIME SETUP:
1. Install Node.js, PostgreSQL, and Git for Windows
2. Run setup-ssh.bat and follow instructions to add SSH key to GitHub
3. move the .env file from /adal-keep to /adal-keep/adal-keep-backend
4. Run: cd adal-keep-backend && npx knex migrate:latest

DAILY USE:
• Double-click start.bat
• Wait ~10 seconds for browser to open
• Use the app!

UPDATING:
• Click "Check for Updates" in Settings page
• OR run: git pull
• Restart start.bat to apply changes
