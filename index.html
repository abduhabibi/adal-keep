No headless browser. No cloud dependency. No black boxes. Adal Keep attaches to a visible Brave instance over CDP, so the operator sees every click and can take over at any moment.

⚙️

Runtime

Node.js 20+ with ES modules. Express 4 for HTTP. Custom HMAC token auth in HTTP-only cookies.

Data

SQLite in WAL mode with 8s busy timeout. Knex for migrations and queries. Everything ships in a single file.

SQLite · Knex · WAL

puppeteer-core · CDP

Engineering

Every bug we hit — and the fix.

Real problems, solved deterministically. Verification loops beat AI for anything that can be checked. AI is reserved for the cases where the state is genuinely ambiguous.

Session Loss

LMIS sessions expire mid-workflow

Before every job, we navigate to the target page and check if we've been redirected to /auth. Two consecutive redirects = session dead, perform full login. One successful page load = session alive, skip login entirely. Saves 30s and prevents form-fill races.

Upload Verification

"Upload Complete" appears before the upload completes

LMIS shows the completion text the moment a file starts uploading. We wait for filepond's internal state (filepond--item-processing-complete) AND a 2-second stability check before clicking Submit. If Submit doesn't close the modal, we re-attach the file and retry up to 3 times.

Tab Collision

Two parallel jobs fighting over one tab

Early versions reused any LMIS tab across lanes. When two jobs ran at once, one would page.goto() the tab out from under the other mid-click. Fix: per-lane tab cache. Each lane owns one tab for its lifetime; sequential jobs in a lane reuse it. Three lanes = three tabs, no cross-talk.

React Inputs

Keycloak shows nuzlnuzla instead of nuzla

Puppeteer's .type() appends instead of replacing when React's value binding doesn't register a select-all. Fix: use the native property setter (HTMLInputElement.prototype.value) + dispatch synthetic input/change/blur events. Then verify the value stuck; if not, fall back to Ctrl+A keyboard events.

Overlay Blockers

SYSTEM ALERT modal swallows every click

LMIS shows a persistent warning modal on every page load. Puppeteer's elementHandle.click() throws silently when the target is covered. Fix: before clicking, run document.elementFromPoint(x, y) and check whether something else is on top. If covered, dismiss overlays first (detected by title text), then click at absolute coordinates via page.mouse.click().

Background Throttling

Uploads 4× slower when operator switches tabs

Chromium slows timers and network in background tabs by 90%+. Two-layer fix: launch Brave with --disable-background-timer-throttling --disable-renderer-backgrounding, and send CDP Emulation.setFocusEmulationEnabled { enabled: true } on every tab. The page thinks it's always focused. Uploads run at full speed regardless of what the operator is looking at.

reCAPTCHA & Images

Broken captcha because images were blocked

Images were globally disabled to save bandwidth (Ethiopian internet). But Musaned's reCAPTCHA renders as an empty crosswalks grid with no tiles to solve. Fix: per-workflow image policy. Off for LMIS, on for Musaned. Implemented as a per-job flag that the request interceptor reads on every request — a reused tab can flip mid-flight.

Principles

How we think about automation.

01

Determinism over AI where possible

Every action has a verifiable outcome. If the outcome doesn't match, retry with a different strategy. Only hand off to a model when the state is genuinely ambiguous.

02

Human-in-the-loop for consequential actions

The final submit on LMIS and Musaned is always human-clicked. The system does the tedious 90% and hands the operator a "continue" button. No silent submissions.

03

Failures leave artifacts

Failed jobs take a screenshot, dump the page text, and leave the tab open. Nothing is lost. The operator sees exactly what the system saw when it gave up.

04

Per-workflow policies

Images on/off, tab reuse, retry behavior — all configurable per workflow. No global "one size fits all" flags. A bandwidth saver for LMIS is a showstopper for reCAPTCHA.

05

State survives pauses

Multi-stage workflows preserve their stage in pause_reason. A job can be paused for hours and resume exactly where it left off. No context is lost.

06

Leave the browser open

We never auto-close a tab on failure. The operator might want to inspect, complete a step manually, or copy something. The tab is theirs until they say otherwise.

Automation that respects reality.

Slow networks. Flaky third-party portals. React-controlled inputs. reCAPTCHA. We engineered around all of it.
