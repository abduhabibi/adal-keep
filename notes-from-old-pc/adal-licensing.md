Adal Keep is sold after a 21-day (3-week) trial (14 days from 2026-10-18; 21 days since 2026-11-03). After the trial the server refuses every /api call and /uploads file and background work stops; the lock screen shows the CBE payment QR (`adal-keep-frontend/public/adal-payment.webp`; the image itself may still read 50,000), the seller phone 0995668080, and the server PC's 6-digit PC number (from Windows MachineGuid, last digit Luhn). The customer calls, says the number, and types the current Google Authenticator code; since 2026-11-03 each code gives 6 months for 30,000 ETB (PAID_DAYS=182, added on top of any remaining paid time; signed `paid_until`; a code works once). PCs unlocked "forever" before that stay open. A renewal reminder shows in the last 14 days, a banner in the last 7.

When the main PC is locked, every PC is: browsers on other PCs get the same lock screen from the server, and the Companion stops sending files and opens that page (adal-companion/license.go). The lock screen says 10% of the payment goes to charity (changed from 30% on 2026-10-20) and lists everything Adal Keep does.

The user (the seller) makes each customer's Authenticator entry with `seller/Adal Seller (PRIVATE).html`, generated by `node seller/make-seller-page.mjs` (gitignored, contains the key).

**Why:** the user chose one Authenticator entry per customer so a code read to one customer cannot unlock another PC.

**How to apply:** `ADAL_LICENSE_KEY` in adal-keep-backend/.env must never change or be committed — every sold PC's codes derive from it; the build stops without it. Core logic: adal-keep-backend/src/services/subscription.js. The old master code 759126348 and the 180-day DB-encrypting "destroy" mode were removed. Keep the USB and the local `Adal Keep USB/` folder in sync after every rebuild ([[usb-workflow]]).
