Enterprise Architecture

Designed for reliability, security, and long-term operational stability in demanding environments.

  • ✓
    SQLite + PostgreSQL

    Local SQLite for single-office deployments. PostgreSQL ready for multi-office scale.

  • ✓
    Portable Node.js Runtime

    Bundled runtime in installer. No system dependencies required on client machines.

  • ✓
    Hardware-Bound Licensing

    Fingerprint-locked subscriptions with trial activation and payment verification.

  • ✓
    Background Learning Agent

    Go binary monitors file activity and app usage to reverse-engineer workflow patterns.

  • ✓
    Auto-Reconnect

    Checks connectivity every 60 seconds. Syncs subscription, AI status, and pending events when online.
